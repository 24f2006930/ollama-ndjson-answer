# Ollama NDJSON Stream Reconstruction

Repository name: `ollama-ndjson-answer`

Repository description: `Public JSON endpoint for reconstructed Ollama-style NDJSON streams A, B, and C.`

The root endpoint `/` returns the required raw JSON answer. `/answer.json` returns the same JSON.

Deploy this repository as a Render Blueprint using `render.yaml`, then submit the service base URL (the root URL ending in `.onrender.com`) to the grader.
